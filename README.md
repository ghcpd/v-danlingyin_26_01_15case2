# Habit Tracker

A lightweight single-page habit tracker that lets you add habits with a frequency, mark them complete, and remove them. Built with React 18, TypeScript, Vite, and Tailwind CSS.

## Tech Stack
- React 18
- TypeScript (strict)
- Vite
- Tailwind CSS
- pnpm

## How to Run
1. Install dependencies: `pnpm install`
2. Start dev server: `pnpm dev`
3. Open the URL shown in the terminal (typically `http://localhost:5173`).

## Features
- Create a habit with name and frequency (daily/weekly/monthly)
- View habits in a list
- Toggle a habit as completed or not completed
- Delete a habit
- Local state only (no persistence)
